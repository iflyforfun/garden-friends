# Garden Friends Tycoon

A simple browser-based incremental/tycoon game built with **HTML, CSS, and JavaScript**.

## Features

* Plant Garden Friends to generate currency.
* Purchase progressively more expensive friends and buildings.
* Automatic resource generation from owned upgrades.
* Unlock new shop items as the game progresses.
* Cheat system for testing resource amounts.
* Responsive 3-column shop layout.

## Progression

Garden Friends → Butterfly Friends → Ladybug Friends → Bunny Houses → Squirrel Friends → Hedgehog Friends → Bird Nests

Each upgrade generates the resource required by the previous tier, creating an incremental progression system.

## Technologies

* HTML5
* CSS3
* JavaScript

## How to Run

Open `index.html` in a web browser. No server or dependencies are required.
